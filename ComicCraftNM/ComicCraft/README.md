# ComicCraft — Clean Error-Free Setup

This version replaces the old FastAPI/Gemini project.

## Included
- app.py
- ComicCraft UI
- Story prompt
- 5 comic panels
- Dialogue + scenes
- Comic-style design

## Removed
- Gemini API
- .env
- FastAPI
- Uvicorn
- requirements.txt
- pip install
- external Python packages

## Run

Open PowerShell inside this folder:

    python app.py

Then open:

    http://127.0.0.1:8000

Only Python 3 is required.
